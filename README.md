# مشروع تطبيق شركة الجواد الدولية العربية الرسمي - Flutter

تطبيق مهني احترافي متكامل مبني لخدمات التشغيل، الصيانة، النظافة العامة، ومكافحة الآفات للشركة.

## هندسة وبنية التطبيق (Architecture)
تم تصميم التطبيق بالكامل بالاعتماد على **Feature-Based Clean Architecture**:
- **Core**: يحتوي على الثيم الموحد (Material 3)، الموجه والمولد التلقائي للمسارات (GoRouter)، والبيانات المركزية.
- **Data**: نماذج البيانات (Models) والمستودع المحلي (Local Repository Abstraction) المهيأ لسهولة التبديل والاتصال بأي واجهة برمجية خارجية API أو Firebase مستقبلاً.
- **Features**: واجهات التطبيق المفصولة بشكل كامل من شاشات دليل الخدمات، تقديم الطلبات، سجل مشاريعنا، وقائمة المزيد.

## كيفية تشغيل وبناء التطبيق
1. تأكد من تحميل حزمة Flutter SDK.
2. قم بتثبيت الحزم والمكتبات المعتمدة:
   ```bash
   flutter pub get
   ```
3. تشغيل التطبيق في بيئة التطوير:
   ```bash
   flutter run
   ```
4. بناء نسخة Android المخصصة للمعاينة والاختبار (APK Release):
   ```bash
   flutter build apk --release
   ```
5. بناء نسخة الويب المستهدفة للمعاينة من قبل الإدارة (Web Release):
   ```bash
   flutter build web --release
   ```
   *الملفات المتولدة داخل مجلد `build/web` جاهزة تماماً للرفع المباشر والاستضافة الاستاتيكية.*

## تبديل الشعار والبيانات المركزية
- **الشعار**: متواجد داخل مسار الكود في ويدجيت مركزي معزول موثق تحت `lib/core/widgets/custom_placeholder.dart`.
- **البيانات والخدمات**: مجمعة بالكامل بشكل مركزي داخل ملف الكود `lib/core/constants/app_data.dart` لتعديلها دفعة واحدة.
